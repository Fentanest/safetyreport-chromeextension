## 바뀐 점

### 개선
- 확장 팝업을 열면 마지막으로 확인한 연결 상태를 바로 보여주도록 바꿨습니다. 필요한 연결 확인은 화면 뒤에서 진행하며, 새로고침 버튼을 누르면 현재 상태를 다시 확인할 수 있습니다.
- 팝업·설정 화면과 신고 내역 창의 입력칸, 버튼, 간격을 다듬고 다크 모드에서 글자와 연결 상태를 더 알아보기 쉽게 개선했습니다.

### 버그 수정
- 주소에 `www`가 없는 안전신문고 사이트에서도 차량번호·주소별 신고 내역 창이 나타나도록 고쳤습니다.
- 서버나 연결 방식을 바꿀 때 이전 연결 상태가 잘못 표시되던 문제를 고쳤습니다.
- 설정 화면을 열어 둔 상태에서도 연결 끊김과 복구가 반영되도록 고쳤습니다. 연결 상태가 갱신되어도 입력 중인 설정과 연결 테스트 결과는 유지됩니다.
