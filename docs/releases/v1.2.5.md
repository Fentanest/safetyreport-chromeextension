## 수정

- “이 주소의 내 신고” 패널을 한 번 열면 지도 이동, 차량번호 입력, 다른 곳 클릭, Escape, 창 전환을 해도 유지됩니다. X 버튼으로 직접 닫으며, 본문 접힘은 수동 접기 버튼으로만 바뀝니다.
- 주소 표시 요소가 교체되거나 일시적으로 비어도 결과 창이 사라지지 않습니다. 새 주소는 같은 창에서 조회하고 이전 주소의 늦은 응답은 무시합니다.
- 좁은 화면에서 차량·주소 창을 함께 배치하고 내부 스크롤을 사용합니다. 계정 전환 시 이전 계정 결과는 즉시 지웁니다.
