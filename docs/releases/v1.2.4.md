## 바뀐 점

### 개선

- 차량번호를 4글자(예: 5902)만 입력해도 차량 신고 내역 창이 자동으로 열립니다. 클라우드와 내 서버 모두 입력한 부분 번호가 포함된 차량의 내 신고를 찾습니다.
- 신고 내역 창을 닫아도 차량번호나 주소를 바꾸면 해당 창이 다시 열립니다.
- 주소를 골라도 주소별 신고 내역 창이 자동으로 열리지 않던 문제를 고쳤습니다.
