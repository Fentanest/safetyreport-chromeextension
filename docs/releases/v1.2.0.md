## 바뀐 점

### 새 기능
- 신고 분류에 **안전신고**와 **생활불편**이 추가되었습니다. 지금까지 '기타'로 묶여 보이던 신고를 종류별로 볼 수 있습니다.

### 개선
- 신고 화면에서 차량번호·주소 옆에 나오는 신고 내역 창을 카드와 아이콘으로 정리해 한눈에 보기 쉽게 다듬었습니다.
- 확장 팝업과 설정 화면도 같은 모양으로 정리했습니다.

### 업데이트 안내
- 커뮤니티 서버를 옮겼습니다. 카카오 로그인으로 쓰던 분은 업데이트 후 설정 화면에서 카카오로 한 번 다시 로그인해 주세요.
