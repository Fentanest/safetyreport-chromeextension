# 확장 개인정보 안내 (2026-10-27)

카카오 로그인 버튼을 누르면 기존 Supabase 프로젝트의 인증을 시작합니다. 확장은 클라우드로만 동작하며 1.3.0부터 PC 앱(셀프호스팅) 서버에 연결하지 않습니다.

조회 항목은 차량번호·신고번호·날짜·결과·처분·주소·기관·담당자·법규·별점 등입니다. 본인이 커뮤니티에 공유한 완료 신고만 조회하며 금액·좌표 등 계약이 제공하는 정보를 포함합니다. 확장 카드에 제목·본문·답변 원문·첨부를 표시하지 않습니다.

Supabase access/refresh token은 신뢰된 확장 컨텍스트만 접근할 수 있는 `storage.local`에 보관합니다. content script나 안전신문고 페이지에 비밀키를 전달하지 않습니다. background가 목적지와 고정 API 경로를 결정하고 DTO allowlist의 결과만 반환합니다. 오류·로그·캡처에 비밀키를 기록하지 않습니다.

검색어는 Supabase Edge Function에 HTTPS POST 본문으로 전송합니다. Supabase 통신 권한은 빌드된 프로젝트의 HTTPS origin 하나에 한정합니다. 안전신문고 패널과 스타일은 `http://www.safetyreport.go.kr/*`, `https://www.safetyreport.go.kr/*`와 `www`가 없는 두 주소의 최상위 페이지에 적용하며, 어느 주소에서도 토큰을 페이지에 전달하지 않습니다. 알림·알람·임의 서버 접근 권한은 요청하지 않습니다.

1.2.6 이하에서 업데이트하면 처음 실행할 때 이전에 저장한 PC 서버 주소, API 키, 크롤링 상태와 받아 둔 PC 서버·알림 권한을 삭제합니다. 이때 PC 서버로 요청을 보내지 않습니다.

조회 결과는 worker 메모리에 최대 60초·50개 키 동안 보관합니다. 계정 변경 때 요청을 취소하고 캐시를 폐기합니다. 명시적 로그아웃은 이 확장의 클라우드 세션을 종료하며 PC·모바일·지도 세션을 전역 종료하지 않습니다. 패널의 화면 데이터는 60초가 지나 다시 열면 재조회합니다.

검색 카드의 안전신문고 원문 링크에는 공식 사이트의 별도 로그인이 필요할 수 있습니다. 커뮤니티 지도 링크는 지도 사이트 자체의 로그인·열람 기준을 따릅니다. 공유 동의·자료 삭제는 기존 계정 서비스의 정책과 절차를 따릅니다. 운영자의 실제 개인정보처리방침·연락처·보유기간은 기존 서비스 정본을 확인해야 합니다.
