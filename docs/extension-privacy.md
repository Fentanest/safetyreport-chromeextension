# 확장 개인정보 안내 (2026-09-30)

이 확장은 사용자가 직접 카카오 로그인 버튼을 누르면 기존 Supabase 프로젝트의 카카오 인증을 시작합니다. 로그인 후 본인이 커뮤니티에 공유한 **완료 신고**만 조회합니다. 확장과 서버가 처리하는 항목은 계정 식별·세션, 검색한 차량번호 또는 주소, 조회된 신고의 원본 차량번호·신고번호·날짜·결과·처분·위치·기관·담당자·법규·별점 등입니다. 신고 제목·본문·답변 원문·사진·첨부·별점 사유는 이 조회 API에 포함하지 않습니다.

검색어와 개인 조회 결과는 Supabase Edge Function으로 암호화된 HTTPS 요청을 통해 전달됩니다. 검색어는 URL 대신 POST 본문에 넣습니다. access/refresh token은 신뢰된 확장 컨텍스트만 접근할 수 있는 로컬 저장소에 보관하고 코드에서는 worker가 사용합니다. 안전신문고 페이지의 스크립트에 토큰을 메시지로 전달하지 않습니다. 조회 결과는 확장 worker 메모리에 최대 60초 동안만 재사용하고 로그아웃·계정 전환 시 지웁니다. 별도의 서버 URL/API 키나 주기적 크롤링 상태 조회는 사용하지 않습니다.

신고 카드의 **안전신문고 원문** 링크를 누르면 공식 `www.safetyreport.go.kr`로 새 탭을 엽니다. 원문 보기에는 안전신문고 사이트의 별도 로그인이 필요할 수 있습니다. 커뮤니티 지도 링크는 지도 사이트 자체의 로그인·열람 기준을 따릅니다. 확장의 로그아웃은 이 확장에 저장된 Supabase 세션만 종료하며 PC·모바일·지도 세션을 전역 종료하지 않습니다.

확장 설정에서 언제든 로그아웃할 수 있습니다. 커뮤니티 공유 동의·자료 삭제는 기존 계정 서비스의 정책과 절차를 따릅니다. 운영자의 실제 개인정보처리방침·연락처·보유기간은 기존 서비스의 정본을 확인해야 하며, 이 문서에서 임의로 정하지 않습니다.
