# 확장 개인정보 안내 (2026-10-03)

옵션에서 셀프호스팅 또는 클라우드를 선택합니다. 셀프호스팅은 사용자가 입력한 safetyreport 서버와 API 키로 조회하고, 클라우드는 사용자가 카카오 로그인 버튼을 누르면 기존 Supabase 프로젝트의 인증을 시작합니다. 셀프호스팅에서 확장의 별도 카카오 로그인을 강제하지 않습니다. 서버 자체의 인증·동의 요구는 그대로 적용됩니다.

조회 항목은 차량번호·신고번호·날짜·결과·처분·주소·기관·담당자·법규·별점 등입니다. 클라우드는 본인이 커뮤니티에 공유한 완료 신고만 조회하며 금액·좌표 등 계약이 제공하는 정보를 포함합니다. 셀프호스팅은 서버 검색 범위의 처리중 신고도 포함합니다. 확장 카드에 제목·본문·답변 원문·첨부를 표시하지 않습니다. 셀프호스팅 크롤링 완료 알림은 기존 서버가 제공한 신고번호·제목 또는 중복 변경 정보를 사용할 수 있습니다.

API 키와 Supabase access/refresh token은 신뢰된 확장 컨텍스트만 접근할 수 있는 `storage.local`에 보관합니다. 과거 sync에 남은 서버 설정은 이 저장소로 먼저 옮긴 뒤 sync의 키 사본을 제거합니다. content script나 안전신문고 페이지에 비밀키를 전달하지 않습니다. background가 설정된 모드·목적지와 고정 API 경로를 결정하고 DTO allowlist의 결과만 반환합니다. 오류·로그·캡처에 비밀키를 기록하지 않습니다.

클라우드 검색어는 Supabase Edge Function에 HTTPS POST 본문으로 전송합니다. 셀프호스팅은 기존 서버 API의 GET 경로/쿼리로 전송하며 HTTP 또는 HTTPS는 사용자가 설정한 주소를 따릅니다. 서버 접근 권한은 입력한 origin 하나만 요청합니다. 셀프호스팅 상태 폴링·시작/완료 알림·처리중 배지는 해당 모드에만 있습니다. 알림을 켜면 알림 권한을 요청합니다.

조회 결과는 worker 메모리에 최대 60초·50개 키 동안 보관합니다. 모드·서버·계정 변경 때 요청을 취소하고 캐시를 폐기합니다. 선택과 각 모드 설정은 재시작 후 유지합니다. 모드를 바꿔도 클라우드 세션을 삭제하지 않습니다. 명시적 로그아웃은 이 확장의 클라우드 세션을 종료하며 PC·모바일·지도 세션을 전역 종료하지 않습니다. 서버 origin과 키의 SHA-256 지문 및 직전 크롤링 실행 여부를 로컬에 보관해 worker 재시작 뒤 알림 상태를 구분합니다.

검색 카드의 안전신문고 원문 링크에는 공식 사이트의 별도 로그인이 필요할 수 있습니다. 셀프호스팅의 최근 답변 링크와 내 서버 열기는 자기 서버 관리 화면으로 이동합니다. 커뮤니티 지도 링크는 지도 사이트 자체의 로그인·열람 기준을 따릅니다. 공유 동의·자료 삭제는 기존 계정 서비스의 정책과 절차를 따릅니다. 운영자의 실제 개인정보처리방침·연락처·보유기간은 기존 서비스 정본을 확인해야 합니다.
